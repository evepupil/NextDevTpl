# NextDevTpl v2.6.0

NextDevTpl 2.x 的首个完整可组合版本。这个版本把完整模板升级为可按模块、服务
适配器和部署目标生成的独立项目，并建立了长期兼容性基线。

## 主要更新

### 模块化项目生成器

- 新增 `create-nextdevtpl` CLI，提供 `minimal`、`saas`、`ai-saas` 和自定义组合。
- 生成结果只保留已选择的源码、依赖、环境变量、数据库 Schema 和翻译。
- 支持 Server、Docker Compose、Vercel 和 Cloudflare Workers 四种部署目标。
- 生成项目拥有全部源码，线上运行不依赖生成器。

### 服务适配器

- 支付、存储、邮件、AI、后台任务和限流使用稳定内部接口。
- 官方提供 Creem/Stripe、S3/R2、Resend/SMTP/Cloudflare Email、OpenAI
  Compatible/Anthropic/Workers AI、Inngest/Workflows 和 Upstash/Cloudflare
  Rate Limiting 适配器。

### Cloudflare Workers

- 使用 OpenNext 生成 Worker，支持 Neon、R2、Workers AI、Cloudflare Email、
  Rate Limiting 和 Workflows Bindings。
- 完整 `ai-saas` 组合压缩后为 `2280.94 KiB gzip`，可进入 Workers Free 的
  `3 MB` Worker 大小限制。
- Cloudflare 生成结果使用 Workers 兼容的 `console` logger，避免 Node.js stdout
  写入造成运行时 500。

### 兼容性与部署

- CI 固化 `minimal-server`、`saas-docker`、`saas-vercel` 和
  `ai-saas-cloudflare` 四组矩阵。
- Server standalone、Docker Compose、Vercel Preview 和 Cloudflare Worker
  均完成真实健康检查。
- 增加升级指南、兼容性故障排查、发布包校验和 2.x 兼容承诺。

## 安装

需要 Node.js 24 和 pnpm：

```bash
pnpm dlx create-nextdevtpl@2.6.0 my-app --preset saas --target vercel
```

查看全部组合参数：

```bash
pnpm dlx create-nextdevtpl@2.6.0 --help
```

## 升级说明

生成代码归项目所有，2.x 不会覆盖已有项目。升级时用相同选择生成一个对照项目，
审查差异后分批合并。完整步骤见 `docs/升级指南.md`。

## 已知限制

- Node.js 支持范围为 `>=24 <25`。
- D1、Hyperdrive recipe 和生成后模块追加/卸载命令尚未提供。
- Cloudflare 目标暂不提供 Sentry 上报，使用 Workers 日志与 `console` 错误记录。

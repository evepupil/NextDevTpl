## 职责与边界

本模块负责向模板使用者解释如何选择、接入、验证和运营 3.x 能力，并记录稳定版
兼容证据。文档只描述已经实现的功能，规划内容继续保留在 roadmap 和模块设计中。

## 结构与数据流

```text
README -> 生成器选择 -> 环境与隐私配置 -> 事件接入 -> 驾驶舱/告警 -> 故障排查
```

## 关键决策

- 中英文文档保持相同指标名称、公式、限制和验证步骤。
- 提供默认事件字典，并明确首次价值和核心动作必须由项目定义。
- 每个供应商说明配置、能力、数据延迟、保留和故障状态。
- 隐私文档覆盖同意、撤回、内部 ID、禁止字段和数据删除。
- 发布说明区分已实现能力、实验能力和计划能力。
- 用户必须通过真实事件和查询确认接入，不能只检查环境变量。

## 当前实现

2.x 已有日志、Sentry、Axiom、健康检查和限流说明；产品分析事件、运营驾驶舱、
收入指标、AI 成本和告警文档尚未存在。

## 验证方式

- 对照源码、recipe、环境变量和生成器参数检查文档。
- 检查中英文页面、导航和内部链接。
- 运行全部项目门禁、发布包检查和官方组合验证。
- 按文档从空项目完成一次真实埋点、查询、驾驶舱和通知验收。

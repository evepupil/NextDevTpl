# 纯前端导出

> 模块定位：把同一套皮肤导出为不含后端的独立前端项目，页面使用演示数据
>
> 对应代码：`packages/create-nextdevtpl/`（导出模式）、`src/core/skin/demo/`（演示数据与本地动作）、
> `src/core/plans/`（共用套餐配置）、`src/modules/`（运行时与页面出口）、皮肤包 `demo/`（皮肤演示数据）
>
> 所属里程碑：[M5 - v4.5 纯前端导出](../roadmap4.x.md#m5)
>
> 当前状态：M5 纯前端导出已完成
>
> 最近更新时间：2026-11-07

## 职责与边界

纯前端导出负责：

- 导出模式：基于选中的皮肤，生成只含页面视图、外壳、基础组件、变量、字体、素材和演示数据
  的独立项目。
- 演示数据：核心按[视图契约](视图契约.md)为每个页面提供通用演示数据，皮肤可以用自己的
  `demo/` 替换。
- 演示动作：登录、注册、提交表单、发起购买等动作返回预设的成功或失败结果，不发起网络请求。
- 裁剪：数据库、登录、支付、积分、存储、邮件、任务、限流、分析、运营等模块的源码、依赖、
  环境变量、接口路由和中间件里的会话保护全部移除。

纯前端导出不负责：

- 皮肤本身和视图约定，见[皮肤系统](皮肤系统.md)和[视图契约](视图契约.md)。
- 把纯前端项目重新接回后端；需要真实功能时使用完整项目。
- 管理后台和文档站的导出。

## 结构与数据流

```text
选择皮肤 + 导出模式
   │
   ▼
复制皮肤视图、外壳、基础组件、变量、字体和素材
   │
   ▼
路由外壳改为演示取数：从演示数据读取符合约定的数据
   │
   ▼
动作改为演示实现：返回预设结果，不发网络请求
   │
   ▼
移除全部后端模块、依赖、环境变量、接口路由和会话保护
   │
   ▼
独立项目：零环境变量即可安装、构建和启动
```

导出项目包含 17 个面向用户的页面。控制台页面无需登录即可访问，使用固定的演示用户。

## 关键决策

- 演示数据按视图约定的类型编写。约定一旦变化，类型检查会发现过期的演示数据。
- 演示动作不发起业务网络请求，状态只保存在当前浏览器标签页内存中；正常 Next 软导航请求保留。
- 同一套皮肤的完整项目和纯前端项目使用同一份视图代码，外观保持一致。
- 通过稳定的页面取数、页面控制器、`view` 与根运行时出口替换行为；完整项目继续真实实现，
  演示项目接本地实现。皮肤视图合同与 `viewApi` 不变，不复制每套皮肤的页面，不用业务源码
  字符串替换来移除后端。
- 本轮纯前端目标只开放 `server`；其他部署目标在生成前明确拒绝，完整项目的四个目标不变。

### 演示数据

皮肤清单可选 `demo: { data: "demo/data.json" }`，保持清单格式版本 1。入口必须是 `demo/` 下
的普通 JSON 文件并列入 `files` 哈希，最多 262144 字节；拒绝链接、越界与重复 JSON 键。
未指定时用核心默认样例，皮肤只能覆盖下列业务数据，不能配置行为或覆盖金额和权益。

```ts
interface DemoData {
  schemaVersion: 1;
  snapshotAt: string;
  workspace: {
    user: {
      id: string;
      name: string;
      email: string;
      image: string | null;
    };
    plan: {
      id: PlanId;
      interval: "month" | "year";
      isActive: boolean;
      cancelAtPeriodEnd: boolean;
      currentPeriodEnd: string | null;
      pendingPlanId: PlanId | null;
      pendingPriceEffectiveAt: string | null;
    };
    credits: {
      balance: number;
      totalEarned: number;
      totalSpent: number;
      batches: readonly { remaining: number; expiresAt: string | null }[];
      transactions: readonly DemoCreditTransaction[];
    };
    billingHistory: readonly DemoBillingHistoryItem[];
  };
  support: { tickets: readonly DemoTicket[] };
}

interface DemoCreditTransaction {
  id: string;
  type: CreditTransactionType;
  amount: number;
  description: string | null;
  createdAt: string;
  grant?: { planId: Exclude<PlanId, "free">; interval: "month" | "year" };
}

interface DemoBillingHistoryItem {
  id: string;
  eventType: SubscriptionHistoryEventType;
  createdAt: string;
  effectiveAt: string;
  fromPlanId: PlanId | null;
  toPlanId: PlanId | null;
}

interface DemoTicket {
  id: string;
  category: TicketCategory;
  priority: TicketPriority;
  status: TicketStatus;
  subject: string;
  createdAt: string;
  messages: readonly {
    id: string;
    content: string;
    createdAt: string;
    author:
      | { kind: "current-user" }
      | { kind: "staff"; id: string; name: string; image: string | null };
  }[];
}
```

- 每层拒绝未知键。覆盖文件根节点必填格式版本，其余对象可按字段提供子集；对象递归合并、
  数组整体替换且元素完整，只有明确可空的字段接受 `null`，合并后完整校验。
- 计划编号、交易类型、账单事件和工单枚举来自无副作用的核心合同。月度赠送交易必须提供
  付费计划编号及周期，其他交易禁止 `grant`；收支方向、描述和姓名等展示值由核心映射。
- 编号为最多 64 字符的 ASCII 字母、数字、下划线或连字符，各集合编号唯一。姓名最多 80、
  邮箱 254、主题 5-200、消息 1-5000、交易描述最多 500 字符。
- 集合上限为工单 50、每单消息 50、积分批次 12、交易 100、账单历史 50。计数必须是安全整数，
  汇总非负，交易金额与批次剩余数为正，批次余额合计等于展示余额。
- 日期只接受规范 UTC 往返一致格式。固定的 `snapshotAt` 是样例参考时间，默认
  `2026-11-07T00:00:00.000Z`；批次相对这个时间尚未到期。校验与到期摘要不读取当前时钟，
  避免样例过几个月便无法生成。真实本地操作的消息和账单时间可使用操作时的时间。
- 免费计划使用月周期且没有有效订阅、取消或待切换状态；取消需有效订阅与周期结束日期，
  待切换计划和生效日期必须配对。历史样例不要求等于完整账本，累计收支不与截短交易强绑。
- 头像仅允许空值或皮肤内已登记、已声明授权的站内资源；不接受外部 URL 或脚本。运行时头像
  预览另存瞬时地址，替换或根 Provider 销毁时释放，软导航不提前释放。
- 展示时交易、账单和工单按创建时间倒序，消息正序，相同时间保持输入顺序；只排序副本。
  序列化按 ASCII 对象键排序，保留数组次序，生成器计算 SHA-256，不在记录中写入数据原文。

### 单一套餐配置与校验源码

- `src/core/plans/` 保存计划编号、名字、币种、金额、折扣、热门标记、月额度、文件限制、队列
  和权益。完整支付配置只关联供应商价格编号；显示 helper 与演示控制器读取同一配置。
- 仍公开的套餐显示 helper 也必须派生数据，不能保留另一份硬编码权益列表或额度。迁移保持
  当前金额、额度、权限、英文和翻译含义不变，不顺带改套餐规则。
- 纯 TypeScript 的数据类型、严格校验、默认样例、合并和稳定序列化只维护一份根源码。
  生成器构建前按白名单机械复制到忽略的源码镜像，保留目录层级并用相对 `.js` 导入；
  包内 `rootDir`、命令入口与 `dist` 布局保持不变。
- 包构建、类型、打包、干净安装和根门禁均刷新同一镜像并核对字节，镜像不提交、不手改。
  模板组装复用根源码，浏览器不带生成器、Node、YAML 或重复 Schema；不执行皮肤代码读取数据。

### 页面控制与状态

- 控制器返回类型集中到各模块的纯 `view/contracts.ts`，保留旧公开出口与方法名称；完整和
  演示实现共用合同，演示版不靠保留带认证、支付或产品动作的原控制器来凑类型。
- 浏览器内存 Provider 放稳定应用根，通过 `src/modules/app-runtime.tsx` 装配，切换语言或页面
  不重建；完整模式为空包装。每实例复制初始数据，服务端没有共享可变状态，首次渲染与水合
  初值相同；刷新或新标签恢复默认样例。业务资料不写浏览器持久存储或 Cookie。
- 登录、注册和 Google 按钮恢复本地用户并去控制台；退出清身份去登录；删除账户清本地数据
  并去登录。忘记、重置、重发、资料和密码表单保留本地校验、忙碌与成功/错误反馈。
- 资料和头像只作本地更新，密码不进入数据仓库。订阅取消、恢复、周期和套餐切换只改内存，
  不创建付款会话。余额、到期提示、历史分页和计划展示由纯映射计算。
- 新工单获得本地编号后软导航详情，回复立即追加。服务端不能先以默认样例查无此单为由阻断
  新工单；客户端页面出口从同一内存仓库取数，刷新后丢失的新工单显示现有 404 界面。
- 运行时达到工单、消息或账单记录上限时，保留本次新增内容，并淘汰最早的旧记录。样例可以
  含未来日期，设备时钟也可能回拨，不能根据时间排序把本次成功返回的新内容直接删掉。
- 需要浏览器状态接管参数的动态视图只导入对应皮肤模块入口，不能在客户端导入包含静态异步
  内容的整份视图映射。默认控制台与空首页改用同步翻译 API，可同时作为同步服务端组件及
  客户端边界中的界面；静态博客、法律与内容页继续允许异步服务端视图。
- 演示预检只检查动态入口的实际可达图：拒绝服务端专用引用及异步视图组件，允许异步事件
  回调；组件树覆盖 JSX 和经 React 导入解析的 `createElement` 调用。完整模式的通用视图合同
  与版本不改；文档明确演示导出的客户端兼容要求。

### 前端裁剪与安装

- 移除全部 API、数据库、动作、服务、适配器、迁移、后台、文档站与未登记路由；中间件只做
  语言路由。保留必要的纯合同和实际引用的前端辅助逻辑，不留下后端入口的间接引用。
- 保留博客/法律本地内容与编译工具，移除文档站集合和文档专用包装；根据最终导入保留需要的
  前端依赖、皮肤字体与动效，供应商 SDK 不得残留。
- 文档站在演示版不可用，核心菜单按可用地址过滤；皮肤自己写的 Hero 或其他入口也按公开导航
  数据决定是否渲染。新增地址字段保持可选，旧皮肤省略时沿用完整项目行为，演示版明确关闭。
- 环境示例不声明变量，安装只运行前端内容编译，不执行数据库迁移、平台绑定类型或数据库
  健康检查。独立 server 项目可直接构建和启动，验收服务不准备数据库。

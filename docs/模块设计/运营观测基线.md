## 职责与边界

本模块负责定义供应商无关的运营事件契约，以及浏览器和服务端共同使用的事件
信封。它不计算收入、不渲染运营页面，也不替代日志和 Sentry。

分析服务不可用时，业务流程继续完成。事件发送失败进入安全日志或内部计数，禁止
把供应商异常直接返回给最终用户。

## 结构与数据流

```text
业务模块 / 页面 -> telemetryService -> noop / logger / PostHog / GA4
                         |
                         +-> 类型校验、身份上下文、同意检查、脱敏
```

事件信封包含 `eventId`、`name`、`version`、`occurredAt`、`source`、
`environment`、`release`、匿名或登录身份、会话、请求、Locale、来源和经过校验的
属性。服务端不信任客户端传入的用户、金额、套餐和权限字段。

## 关键决策

- 事件名称和属性都使用严格 TypeScript 类型与 Zod 校验。
- 客户端分析在用户同意后启用，撤回同意后停止发送并清理供应商标识。
- 服务端必要运营事件只携带内部 ID 和业务状态，禁止附带个人信息与原始内容。
- `noop` 始终可用，未配置分析服务时生成项目仍能正常运行。
- 现有 `logEvent()` 逐步迁移到统一服务，日志继续作为诊断出口之一。
- 同一个业务结果只在权威完成点发出一次，并携带稳定幂等标识。

## 当前实现

当前实现提供 `noop`、结构化日志、PostHog、GA4 和 Umami 五种分析适配器。PostHog 用于产品事件，GA4 用于流量与广告归因，Umami 用于轻量站点分析；适配器都通过统一 `TelemetryAdapter` 契约写入，不携带邮箱、提示词、上传内容或密钥。客户端页面事件经 `/api/telemetry` 接收，并在分析同意后发送；撤回同意后停止发送并清理 GA 状态。

自有身份链路也使用同一个 `hasAnalyticsConsent()` 门禁：匿名 ID、归因值和认证请求头在同意前不会创建或传播，撤回时会清理 first-party Cookie 与 localStorage。选用真实分析适配器时才挂载 `TelemetryIdentityProvider`；`analytics:noop` 生成项目不会初始化可选分析身份。Telemetry 入口按 IP 使用独立限流，限制 16 KiB 请求体，并在请求带有 `Origin` 时校验同源。

已新增 `src/core/services/telemetry.ts`，提供事件名称格式、版本、来源、环境、身份
上下文和 JSON 属性的运行时校验。`sanitizeTelemetryAttributes()` 会递归移除密码、
令牌、授权头、Cookie、邮箱、提示词和上传内容等敏感字段。

`src/adapters/analytics/noop.ts` 和 `logger.ts` 分别提供无外部请求的空适配器与结构化
日志适配器；`createTelemetryService()` 只吞掉适配器失败并调用可选错误钩子，事件输入
校验失败仍会抛出，便于尽早发现开发错误。`analytics:noop` 与 `analytics:logger` 已进入
registry、recipe 和生成器；支付、订阅和积分的服务端完成点已接入，`analytics:none` 仍
会生成内置 noop fallback 以保持业务导入可用。

`src/lib/telemetry/identity.ts` 负责生成受长度限制的匿名 ID，并把首次来源、最近来源
和 UTM 保存到 first-party 存储；服务端只读取规范化的请求头或 Cookie。认证客户端的
请求钩子会携带这些上下文，OAuth 回调依靠 Cookie 继续关联。`TelemetryIdentityProvider`
只在选择真实 analytics 适配器的生成项目根布局初始化上下文；同页和跨标签页的同意变化
会触发初始化或清理。

## 验证方式

- 单元测试事件名称、属性 Schema、版本和上下文合并。
- 测试同意、拒绝、撤回、匿名和登录身份状态。
- 通过适配器契约测试检查映射、批量、超时和失败降级。
- 扫描事件属性，拒绝密钥、Cookie、Authorization 和受限内容字段。
- 生成 `noop` 和 `analytics:none` 组合，确认没有分析依赖、环境变量或外部请求。

当前已验证：`src/test/adapters/telemetry.test.ts` 覆盖稳定事件信封、敏感字段递归移除、
非法事件拒绝、noop、结构化日志和适配器失败降级；`src/test/telemetry/` 覆盖身份、归因、
认证路径和激活入口；生成器测试确认默认 noop、服务装配和未选适配器裁剪；
`src/test/lib/request-body.test.ts` 覆盖 Telemetry 请求体的声明长度和流式长度限制；
`pnpm typecheck` 通过。

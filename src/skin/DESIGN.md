# 默认皮肤

## 视觉变量

默认皮肤沿用 Engineered Spec-Sheet 的暖中性色与 Spruce 主色。浅色底色使用 `oklch(0.985 0.003 95)`，深色底色使用 `oklch(0.165 0.004 60)`；主色在浅色主题使用 `oklch(0.40 0.072 184)`，深色主题使用 `oklch(0.68 0.11 178)`。完整明暗变量和语义色位于 `tokens.css`。

基础圆角为 `0.625rem`。字体由 Geist Sans 提供正文与标题，Geist Mono 用于等宽内容与数字；中文回退顺序沿用全局字体映射。

皮肤工具类包括工程网格、双色光晕、颗粒噪点和柔性阴影。后台共用的 `eyebrow` 与 `mono-data` 类留在核心全局样式。背景、卡片、边框、图表和侧栏继续使用语义变量，明暗主题由核心主题 Provider 管理，默认跟随系统。

## 修改边界

默认皮肤负责主题变量、字体选择、皮肤内部视图和视觉动效。核心全局样式保留 Tailwind 映射、Fumadocs 兼容、应用基础样式、减少动态偏好处理；基础 UI 组件和功能控制器继续由核心模块提供。

可调项限于 `skin.json` 声明的品牌色、圆角、字体候选和默认主题。修改默认视觉变量时保留语义变量名及明暗两套值；不在视图中硬编码业务价格、积分数量或站点配置。Google 图标仅用于 OAuth 登录，Lucide 社交图标仅用于对应外链导航。

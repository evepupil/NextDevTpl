# NextDevTpl 文档

NextDevTpl 2.x 是可组合的 Next.js SaaS 模板。你可以选择产品模块、外部服务实现
和部署平台，生成器只把选中的源码、依赖、环境变量、数据库表和部署文件放进
新项目。生成后的代码归项目自己维护。

## 先确认项目包含什么

生成项目根目录的 `nextdevtpl.generated.json` 是实际选择清单：

```json
{
  "preset": "saas",
  "target": "vercel",
  "modules": ["auth", "dashboard", "marketing"],
  "adapters": { "payment": "payment:creem" }
}
```

先看这份文件，再阅读对应功能文档。未选能力已经从生成结果删除，无需配置。

## 2.x 能力

| 类别 | 已支持内容 |
| --- | --- |
| 生成 | `minimal`、`saas`、`ai-saas`、自定义组合，自动补依赖并裁剪源码 |
| 产品 | 认证、Dashboard、营销页、设置、订阅、积分、管理后台、工单、博客、PSEO |
| 支付 | 统一接口，Creem 或 Stripe，支持订阅、一次性购买和验签 webhook |
| 邮件 | Disabled、Resend、SMTP、Cloudflare Email |
| 存储 | S3 Compatible 预签名上传或 Cloudflare R2 Binding |
| AI | OpenAI Compatible、Anthropic、Workers AI |
| 后台任务 | Inngest 或 Cloudflare Workflows，另有受保护 cron |
| 限流 | No-op、Upstash Redis 或 Cloudflare Rate Limiting Binding |
| 平台 | Server、Docker Compose、Vercel、Cloudflare Workers |
| 运维 | 健康检查、结构化日志、Sentry、Axiom、组合兼容性门禁 |

## 两种使用方式

产品项目推荐使用 `create-nextdevtpl` 创建干净项目。克隆完整仓库适合参与模板
开发、扩展官方模块、运行组合矩阵或准备生成器发布包。

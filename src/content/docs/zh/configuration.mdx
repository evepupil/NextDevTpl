# 配置说明

先查看 `nextdevtpl.generated.json` 中的 `mode`、`modules`、`adapters`、`bindings` 和
`target`，再查看生成后的 `.env.example`。完整模式始终需要站点 URL
(`NEXT_PUBLIC_APP_URL`)，其他变量按生成选择配置。演示模式无需业务环境变量或数据库。

## 演示模式

演示模式在当前浏览器标签页的内存中保存样例状态，不连接真实服务。它不需要 `.env` 文件、
数据库、认证密钥或服务供应商凭证。套餐价格和权益来自项目内统一的套餐配置；皮肤演示数据
只能覆盖允许的样例字段。

## 完整模式基础变量

完整模式始终需要站点 URL `NEXT_PUBLIC_APP_URL`。数据库、认证及服务供应商变量只在生成选择
包含相应能力时填写：

| 变量 | 作用 |
| --- | --- |
| `DATABASE_URL` | PostgreSQL 连接串，供数据库功能、Drizzle 和健康检查使用 |
| `BETTER_AUTH_SECRET` | 签名会话数据；生产环境使用长随机值 |
| `BETTER_AUTH_URL` | Better Auth 回调和 Cookie 使用的站点 URL |
| `NEXT_PUBLIC_APP_URL` | 浏览器链接、metadata 和回跳 URL |
| `NEXT_PUBLIC_APP_NAME` | 站点和邮件显示名称 |

生成 `.env.local` 后，以 `.env.example` 中实际列出的变量为准。没有选中数据库或认证的
自定义项目不应照搬其他组合的必填项。

## 认证与产品

| 能力 | 变量 |
| --- | --- |
| GitHub OAuth | `GITHUB_CLIENT_ID`、`GITHUB_CLIENT_SECRET` |
| Google OAuth | `GOOGLE_CLIENT_ID`、`GOOGLE_CLIENT_SECRET` |
| 套餐价格 | 六个 `NEXT_PUBLIC_PRICE_*` ID，覆盖 STARTER、PRO、ULTRA 的月付和年付 |
| 积分过期 cron | `CRON_SECRET` |
| GA4 浏览器脚本 | `NEXT_PUBLIC_GA_ID` |
| 产品分析 | PostHog：`POSTHOG_API_KEY`、`POSTHOG_HOST`；GA4：`GA4_MEASUREMENT_ID`、`GA4_API_SECRET`；Umami：`UMAMI_WEBSITE_ID`、`UMAMI_API_KEY`、`UMAMI_HOST` |
| 运营告警 | `CRON_SECRET`、可选阈值和已选告警适配器变量 |
| Sentry | `NEXT_PUBLIC_SENTRY_DSN`、`SENTRY_AUTH_TOKEN` |
| Axiom | `AXIOM_TOKEN`、`AXIOM_DATASET` |

OAuth 回调分别是 `/api/auth/callback/github` 和 `/api/auth/callback/google`。生产后台必须填写
正式域名。

| Cloudflare Email | `NEXTDEVTPL_EMAIL`、`EMAIL_FROM` |
| OpenAI Compatible | `AI_PROVIDER` 和所选 OpenAI/DeepSeek/MiMo 密钥与模型 |
| Anthropic | `ANTHROPIC_API_KEY`、`ANTHROPIC_MODEL` |

`ALERT_PAYMENT_FAILURE_RATE_THRESHOLD`、`ALERT_AI_COST_THRESHOLD_MINOR`。金额阈值使用
当前货币的最小单位。生成项目通过 `--alerts` 固定告警适配器；`ALERT_PROVIDER` 只供完整模板
源码使用，生成项目不会再读取它。

## Cloudflare Binding 与密钥

Cloudflare Binding 配在 `wrangler.jsonc`，名称和资源类型应与当前适配器选择一致。密钥使用
`wrangler secret put` 或平台密钥管理配置。不要把真实密钥写进仓库或 `wrangler.jsonc`。
完整模式的 Cloudflare 数据库使用 PostgreSQL 兼容服务；D1 尚不是生成器提供的数据库选项。

演示模式只支持 `server`，不会生成 Cloudflare Binding。

## 配置缺失时

- 完整模式中，选中功能所需的数据库或认证变量缺失时，启动、健康检查或对应操作会失败。
- 所选服务的凭证缺失时，对应操作会返回配置错误。
- `disabled` 邮件和 `noop` 限流适合本地开发，不提供真实投递或防滥用能力。
- 未配置 Axiom 和 Sentry 时仍可使用本地日志与 console 错误输出。
- 浏览器分析遵循同意状态并移除敏感字段；缺少分析凭证不会阻塞核心业务请求。
- 演示模式没有供应商调用；其中的资料、套餐和工单变更不会写回服务器。

## 常改入口

| 路径 | 内容 |
| --- | --- |
| `src/config/site.ts` | 站点名、URL、metadata、社交链接 |
| `src/config/nav.ts` | Header、Footer、Dashboard、Admin 导航 |
| `src/config/payment.ts` | 完整模式产品 ID 和 checkout 配置 |
| `src/core/plans/` | 完整与演示模式共用的套餐额度和展示信息 |
| `src/services/*.ts` | 当前适配器实例 |
| `.env.local` | 本地变量和密钥 |

# 生成器与预设

`create-nextdevtpl` 在生成时复制所选皮肤和应用源码，解析完整模式的模块依赖，裁剪未选择的代码，并写入 `nextdevtpl.generated.json`。生成项目是独立源码，不需要在运行时安装或调用生成器。

需要 Node.js 24 和 pnpm 10。查看当前 CLI 随包提供的全部选项：

```bash
pnpm dlx create-nextdevtpl@4.0.0 --help
```

## 完整模式

完整模式是默认模式。选择预设和目标：

```bash
pnpm dlx create-nextdevtpl@4.0.0 my-app --preset saas --target vercel
```

| 预设 | 默认目标 | 主要范围 |
| --- | --- | --- |
| `minimal` | `server` | 认证和工作区基础页面 |
| `saas` | `vercel` | 营销、认证、设置、管理、支持、订阅和积分 |
| `ai-saas` | `cloudflare` | SaaS 页面以及 AI、博客和 PSEO |
| `custom` | `server` | 显式选择模块和服务适配器 |

完整模式支持 `server`、`docker`、`vercel` 和 `cloudflare`。模块依赖会自动补齐；Worker 专用适配器要求 `cloudflare` 目标，Node 专用适配器不能用于该目标。

```bash
pnpm dlx create-nextdevtpl@4.0.0 my-app \
  --preset custom \
  --modules auth,analytics,operations \
  --target docker \
  --payment stripe \
  --analytics posthog
```

完整模式的旧生成记录如果没有 `mode` 字段，仍按 `full` 解释。新生成记录会明确写入 `mode: "full"`。

## 演示模式

演示模式固定导出 17 条用户路由和 20 个皮肤视图，只支持 `server` 目标。省略目标时默认为 `server`。

```bash
pnpm dlx create-nextdevtpl@4.0.0 my-demo --mode demo --target server
```

演示模式会拒绝显式 `--preset`、`--modules` 和服务适配器参数。保留皮肤来源与 `--palette` 选项，但配色仍只支持内置默认皮肤。演示模式没有数据库、业务 API、Server Actions、后端服务或业务环境变量；本地交互只更新当前标签页内存，刷新后恢复默认样例。演示导出不是静态导出。

## 选择皮肤

省略 `--skin` 等同于 `--skin default`。生成器接受三种来源：

| 来源 | 参数 |
| --- | --- |
| 内置默认皮肤 | `--skin default` |
| 本地目录 | `--skin ./my-skin` |
| 远端 HTTPS 归档 | `--skin https://example.test/skin.tgz --skin-sha256 <64位SHA-256>` |

远端 URL 必须是纯 HTTPS URL，不能带账号口令、查询参数或片段；归档 SHA-256 必填。可选令牌使用 `--skin-token-env NAME` 指定环境变量名，默认读取 `NEXTDEVTPL_SKIN_TOKEN`。令牌值不应写入命令参数；如果显式指定的环境变量不存在或为空，生成会失败。下载令牌不会保存到生成记录，也不会传递给项目安装脚本。

```bash
pnpm dlx create-nextdevtpl@4.0.0 my-app \
  --skin ./my-skin \
  --preset saas
```

生成记录保存皮肤编号、版本、源包摘要和来源类型。远端记录只保留归档摘要，不保存 URL；本地来源不保存绝对目录。

## 选择配色

`--palette <slug>` 仅对内置默认皮肤有效。随包快照包含 149 套 StyleKit 主题，生成期间离线读取。未选配色时默认皮肤 CSS 保持原样；选中后生成记录保存主题编号、快照日期和主题摘要，项目附带所选主题的 `STYLEKIT-LICENSE.txt`。

```bash
pnpm dlx create-nextdevtpl@4.0.0 my-app \
  --preset saas \
  --palette glassmorphism
```

在本地皮肤或远端皮肤上指定配色会被拒绝。配色不提供运行时切换，也不会选择不同页面或布局。

## 常用参数

| 参数 | 取值或用途 |
| --- | --- |
| `--mode` | `full` 或 `demo`；省略为 `full` |
| `--preset` | 完整模式：`minimal`、`saas`、`ai-saas`、`custom` |
| `--modules` | 完整模式自定义模块编号，以逗号分隔 |
| `--target` | 完整模式：`server`、`docker`、`vercel`、`cloudflare`；demo 仅 `server` |
| `--payment` | `creem`、`stripe`、`none` |
| `--storage` | `s3-compatible`、`r2-binding`、`none` |
| `--mail` | `disabled`、`resend`、`smtp`、`cloudflare-email` |
| `--ai` | `openai-compatible`、`anthropic`、`workers-ai`、`none` |
| `--alerts` | `noop`、`email`、`webhook` |
| `--analytics` | `noop`、`logger`、`posthog`、`ga4`、`umami`、`none` |
| `--jobs` | `inngest`、`cloudflare-workflows`、`none` |
| `--rate-limit` | `noop`、`upstash`、`cloudflare-rate-limit` |
| `--skin` | `default`、本地目录或 HTTPS 归档 |
| `--skin-sha256` | 远端归档的 64 位十六进制 SHA-256 |
| `--skin-token-env` | 远端皮肤令牌的环境变量名 |
| `--palette` | 内置默认皮肤的 StyleKit 主题编号 |
| `--yes` | 接受默认提示 |
| `--no-install` | 只生成文件，不安装依赖 |

## 生成后

完整模式按 `.env.example` 配置所选服务并按项目需要初始化数据库。演示模式无需数据库或业务环境变量，安装后可直接启动 Next.js 应用。

```bash
cd my-demo
pnpm dev
```

演示记录的 `modules`、`adapters` 和 `bindings` 为空；`viewModules` 记录八个实际登记视图的模块；`demo.dataSha256` 是合并后演示数据的摘要，不是样例 JSON 原文。演示页面通过内存仓库读取数据；分页、表单输入和业务数据不会写入浏览器持久存储。

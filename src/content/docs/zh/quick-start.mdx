# 快速开始

## 前置要求

| 工具 | 版本 | 用途 |
| --- | --- | --- |
| Node.js | 24.x | 运行生成器和生成项目 |
| pnpm | 10.x | 安装依赖、运行检查与构建 |
| PostgreSQL | 按完整模式选择 | 仅完整项目选中数据库能力时需要；演示模式不需要 |

## 选择生成模式

### 完整项目

按预设生成带所选业务能力的项目：

```bash
pnpm dlx create-nextdevtpl@4.0.0 my-app --preset saas --target vercel
cd my-app
```

默认模式是 `full`。它根据预设或自定义选项保留模块、服务适配器和部署文件；省略
`--preset` 时使用 `minimal`。需要调整组合时，查看[生成器说明](/zh/docs/generator)。

### 前端演示

生成可本地浏览和操作的演示项目：

```bash
pnpm dlx create-nextdevtpl@4.0.0 my-demo --mode demo --target server
cd my-demo
pnpm dev
```

演示模式只支持 `server`，固定包含 17 条用户路由和 20 个皮肤视图。它不包含真实认证、
付款、API、数据库或供应商服务。资料、套餐和工单操作只更新当前标签页的内存样例；刷新
页面或打开新标签页会恢复默认样例。演示模式无需业务环境变量或数据库，也不接受预设、
模块及服务适配器选择。

## 检查生成选择

完整和演示项目都会生成 `nextdevtpl.generated.json`。查看其中的 `mode`、`target`、
`modules` 和 `adapters`，确认项目实际保留了哪些能力。演示项目的后端能力集合为空，
但它仍保留自己的前端页面和视图。

## 完整项目的本地配置

根据生成后的 `.env.example` 创建本地配置：

```powershell
Copy-Item .env.example .env.local
```

macOS 或 Linux：

```bash
cp .env.example .env.local
```

完整模式始终需要站点 URL `NEXT_PUBLIC_APP_URL`。选中数据库和认证时，再配置数据库 URL、
认证密钥和 `BETTER_AUTH_URL`。例如：

```dotenv
DATABASE_URL="replace-with-your-database-url"
BETTER_AUTH_SECRET="replace-with-a-long-random-secret"
BETTER_AUTH_URL="http://localhost:3000"
NEXT_PUBLIC_APP_URL="http://localhost:3000"
```

`.env.example` 已按生成选择裁剪。OAuth、支付、邮件、存储、AI、任务、限流和分析只需
配置当前项目保留的部分。逐项说明见[配置说明](/zh/docs/configuration)。演示项目不需要
复制或填写 `.env` 文件。

## 初始化并启动完整项目

新本地数据库可以直接同步 Schema：

```bash
pnpm db:push
pnpm dev
```

共享环境和生产环境使用迁移：

```bash
pnpm db:generate:init
pnpm db:migrate
```

检查生成的 SQL 后再提交迁移文件。没有选择数据库功能的项目不需要执行数据库命令。

## 首次验证

| 模式 | 检查 | 预期结果 |
| --- | --- | --- |
| 完整 | 页面与登录 | 检查所选页面；选择认证时，邮箱密码账号可以进入工作区 |
| 完整且包含认证与数据库 | 健康检查 | 配置生成的环境变量并初始化数据库后，`/api/health` 返回 HTTP 200 和 `healthy` |
| 完整 | 可选服务 | 只验证生成清单中选择的适配器 |
| 演示 | 页面与操作 | 可直接浏览工作区、设置和工单；操作只改变当前标签页的演示状态 |
| 演示 | 后端边界 | 无需数据库或密钥；没有业务 API，刷新后样例恢复默认值 |

当前健康探针固定检查认证配置和数据库连接。无数据库的自定义完整组合应按所选页面、构建及适配器验证，不以该探针作为可用性标准。

提交前运行项目检查：

```bash
pnpm format
pnpm lint
pnpm typecheck
pnpm test:run
pnpm build
```

准备部署完整项目时查看[部署](/zh/docs/deployment)。演示模式仅提供服务器目标。
